# Wireframe — referência obrigatória

A implementação visual deve manter a hierarquia e a divisão de blocos do wireframe aprovado.

Arquivo de referência:

`docs/reference/wireframe-prmais-eleicoes.png`

## Desktop

1. header PR+;
2. hero “Eleições 2026”;
3. indicador “Apuração ao vivo”;
4. horário da última atualização e progresso;
5. abas Paraná / Presidente / Brasil / Municípios;
6. card principal de Presidente;
7. coluna lateral com transmissão ao vivo;
8. últimas atualizações;
9. busca por município;
10. blocos Governador / Senado / Deputado Federal / Deputado Estadual;
11. mapa do Paraná;
12. fonte dos dados.

## Mobile

A mesma hierarquia deve ser preservada em pilha vertical, priorizando:

1. status ao vivo;
2. ranking presidencial;
3. cargos do Paraná;
4. busca de município;
5. transmissão.

## Identidade

O wireframe define layout, não identidade final.

A implementação deve aplicar:

- logo PR+;
- paleta PR+;
- tipografia PR+;
- componentes editoriais coerentes com o portal.
